# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/teh-hippo/mattershot/security/advisories/new).  Do not include
vulnerability details in a public issue.

Include the affected code type, browser path, or generated label format when known, along with the impact and reproducible steps.  Remove onboarding payloads,
pairing codes, credentials, tokens, personal information, and unrelated private data from the report.
